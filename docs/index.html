kubeezcut-rs — Non-Linear Multi-Track Video Editor & Bezier Keyframe Engine in Rust

kubeezcut-rs is a pure Rust non-linear editing (NLE) core that powers multi-track timeline cutting, ripple edits, cubic Bezier keyframe animation, and 12-band parametric audio EQ. It compiles timeline edits into deterministic render graphs for real-time preview and lossless FFmpeg export.
